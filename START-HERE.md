# Start here

1. Run `npm start` in this folder and open **http://localhost:5173**.
2. Click **Start the first mission**.
3. Advance with **Next scene**. Watch the flow first; inspect code or interview phrasing whenever useful.
4. Follow **Study plan** for the five-day path.
5. Use **Your project stories** to fill in real details behind your resume claims.
6. Finish with a mock in **Interview room**.

For GitHub Pages, upload this folder's contents with `index.html` at the repository root. In **Settings → Pages**, publish the `main` branch from `/(root)`. See [README.md](README.md) for both deployment options.

This is a complete browser simulation, not a live cloud environment. You do not need Snowflake, dbt, Airflow, or any API account.
