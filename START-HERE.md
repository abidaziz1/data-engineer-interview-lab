# Start here

1. Run `npm start` and open **http://localhost:5173**.
2. Read the full project map. Follow the orange T101 record.
3. Press **Next**. Each step shows the data, the operation, and the result.
4. Read the short explanation and open **Interviewer asks** to rehearse aloud.
5. Continue through all 20 steps. End with the five rehearsal prompts.

Allow **2–3 hours including speaking practice**. There are no daily schedules or required quizzes. Use **Aa** for extra-large text and **Project map** to revisit a weak topic.

This is a browser simulation. Real SQL and platform examples are optional. You do not need cloud accounts or API keys to prepare.
